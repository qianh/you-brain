# you-brain 部署与运行

> 版本：v1.0 ｜ 日期：2026-10-27
> 配套：[README](../README.md) ｜ [技术方案](./技术方案.md) ｜ [产品说明](./产品说明.md)

本文覆盖三种跑法：源码开发、桌面端安装包、纯服务器部署。服务器部分是重点——无界面机器上有几处与桌面端不同的地方（登录、密钥、开机自启），单独说明。

---

## 1. 三种形态怎么选

| 形态 | 适用场景 | 采集本机会话 | 界面 | 常驻方式 |
|---|---|---|---|---|
| **源码运行** | 开发、调试、临时试用 | 是 | 浏览器打开本地端口 | 手动 `you-brain daemon` |
| **桌面端** | 日常使用的电脑 | 是 | 菜单栏 + 完整窗口 | Tauri 外壳 + 开机自启 |
| **服务器端** | 7×24 在线，通常担任主设备 | **否** | 远程通过 SSH 隧道看 | systemd 用户单元 |

三者跑的是**同一个核心程序**（`packages/core` + `packages/cli`），只是启动参数和角色配置不同。服务器端不是另一个项目，是同一个二进制的另一种角色。

同一个 Google 账号下的所有设备组成一个整体：会话原文各设备自管，话题册与数字分身全量同步。任何时刻只需一台设备在线。

---

## 2. 前置条件

| 项目 | 要求 |
|---|---|
| 操作系统 | macOS（arm64 / x64）或 Linux（x86_64 / aarch64） |
| Google 账号 | 用于存放数据；Drive 空间按会话原文实际占用计 |
| 模型后端 | 一个 API Key（DeepSeek / GLM / Qwen / Kimi / OpenAI / Claude / 自建 OpenAI 兼容端点 / Ollama），或本机已登录的 AI CLI（`grok` / `claude` / `codex` / `gemini` / `opencode`） |
| OAuth 凭据 | 自己的 Google Cloud 项目，见第 3 节 |
| 源码运行时 | Bun ≥ 1.2.19 |

服务器额外要求：`systemd`（用于开机自启）、能访问 `accounts.google.com` 与 `www.googleapis.com`。

---

## 3. 准备 OAuth 凭据（所有人）

you-brain 默认走**每个人自己的 Google Cloud 项目**，不依赖构建时内置的凭据，也不受「测试用户最多 100 人」的限制。

1. 打开 [Google Cloud Console](https://console.cloud.google.com/)，新建一个项目
2. 「API 和服务 → 库」里启用 **Google Drive API**
3. 「API 和服务 → OAuth 同意屏幕」：
   - User type 选 **Internal**（有 Google Workspace 且同域名），或选 External
   - 选 External 时，把应用**发布到 Production**（Publishing status）
4. 「凭据 → 创建凭据 → OAuth 客户端 ID」：
   - 应用类型选 **桌面应用**
   - 记下 Client ID（形如 `1234567890-xxxx.apps.googleusercontent.com`）和 Client Secret

> **关于 Testing 状态**：如果应用停留在 Testing，Google 只给 7 天有效的 refresh token，之后必须重新登录。选 Internal 或发布到 Production 就不会过期。这是 Google 的策略，不是 you-brain 的限制。

权限范围是完整的 Drive 权限（`https://www.googleapis.com/auth/drive`），用于读取插件、外部 bot 以及用户自己放进 Drive 的文件。

## 4. 源码运行（开发用）

```bash
bun install
bun run typecheck
bun test

# 交互式配置
bun packages/cli/src/index.ts setup

# 前台运行
bun packages/cli/src/index.ts daemon
```

`setup` 可重复执行，会跳过已完成的步骤，中途退出后重新跑会接着上次的进度。

常见参数：

```bash
bun packages/cli/src/index.ts setup --yes                 # 非交互，接受默认值
bun packages/cli/src/index.ts setup --oauth custom \
  --client-id xxx.apps.googleusercontent.com --client-secret <secret>
bun packages/cli/src/index.ts setup --provider deepseek --model deepseek-chat --api-key sk-xxx
bun packages/cli/src/index.ts setup --no-integrations     # 不写任何 AI 客户端配置
```

## 5. 桌面端

### 5.1 打包

```bash
bun run --cwd apps/web build        # Web 界面产物
bun run build:daemon                # 编译 daemon + vendor + sidecar
bun run --cwd apps/desktop bundle   # macOS：产出 .app 与 DMG
```

Linux 用 `apps/desktop/scripts/bundle-linux.sh`（只能在 Linux 上跑，产出 deb 与 AppImage），或手动触发 `.github/workflows/desktop-linux.yml`。

产物落在 `dist/app.noindex/`。

### 5.2 开发时把新构建装进现有 .app

```bash
bun run install:app                 # 默认装到 /Applications/you-brain.app
bun run install:app /path/to/you-brain.app
```

脚本会先停掉正在运行的副本，整体替换 `Resources/{web,vendor}` 与可执行文件，然后重新 ad-hoc 签名。**签名变化会让 macOS 拒绝之前的钥匙串条目**，装完之后需要重新登录一次 Google。

### 5.3 运行

装好后从「应用程序」启动即可。菜单栏常驻，不占 Dock；点击图标打开面板，面板里可以跳到完整窗口。

桌面端由 Tauri autostart 插件在登录时拉起外壳，外壳再拉起 daemon。不需要手动装服务。

## 6. 纯服务器部署

服务器端没有图形界面，也不采集本机会话（本机没有 CLI 会话可采），职责是：提炼网页会话、每日全局沉淀、协议同步，以及对外提供 Web UI 和 MCP。

### 6.1 获取安装包

服务器包是 tar.gz，包含编译好的二进制、Web 界面和原生依赖（`onnxruntime-node`、`sharp`、嵌入模型）。

**只能在 Linux 上构建**：`bun build --compile` 不支持交叉编译，vendor 里的原生二进制也是本机的。

```bash
# 方式一：CI（推荐）
# 在 GitHub Actions 手动触发 server-linux.yml，下载 artifact

# 方式二：在 Linux 机器上自行构建
bun install
bun run --cwd apps/web build
bun run build:server               # 产出 dist/server/you-brain-<version>-<triple>.tar.gz
```

包内结构：

```
you-brain-<version>-<triple>/
  bin/you-brain                    # 编译后的单一可执行文件
  lib/you-brain/web/               # Web 界面静态产物
  lib/you-brain/vendor/node_modules/  # sharp、onnxruntime、嵌入模型运行时
  install.sh
```

`bin` + `lib/you-brain` 的布局与 Linux 桌面包一致，程序会自己找到界面和原生依赖，不需要额外配置环境变量。

### 6.2 安装

```bash
tar -xzf you-brain-0.1.0-x86_64-unknown-linux-gnu.tar.gz
cd you-brain-0.1.0-x86_64-unknown-linux-gnu
./install.sh
```

默认装到 `~/.local/bin/you-brain` 和 `~/.local/lib/you-brain/`。自定义前缀：

```bash
PREFIX=/opt/you-brain ./install.sh
```

脚本会**整体替换** `lib/you-brain`（不是覆盖复制），避免旧版本残留的 `web/`、`vendor/` 导致界面或原生模块错乱。

### 6.3 首次设置（无界面登录）

```bash
you-brain setup --server --skip-brainhub --oauth custom \
  --client-id xxx.apps.googleusercontent.com --client-secret <secret>
```

`--server` 会：

- 把角色写成 `role = "server"`（`config.toml`）
- 关闭全部采集来源（服务器上没有 CLI 会话）
- 跳过 AI 客户端接入与首次回填
- 登录走**无界面模式**：固定回调端口 53682，不尝试拉起浏览器

`--skip-brainhub` 在非交互终端里建议加上，否则会询问是否接管 BrainHub 然后退出。

登录时终端会打印：

```
这台机器没有浏览器。先在你自己的电脑上执行：
  ssh -N -L 53682:127.0.0.1:53682 user@your-server
保持这个终端窗口开着，然后在浏览器里打开下面的链接：
https://accounts.google.com/o/oauth2/v2/auth?...
```

在**自己电脑**上执行那条 `ssh` 命令，然后用浏览器打开链接完成授权。授权完成后服务器上的命令会自动继续。链接有效期 10 分钟。

> 也可以先跑 `you-brain setup --server --yes` 把服务装起来（不登录），之后再在 Web 界面「设置 → 账户与 Drive」里登录并填凭据。

### 6.4 常驻

```bash
you-brain service install          # 生成并启用 systemd 用户单元
sudo loginctl enable-linger $USER  # 无人登录时也能开机自启
you-brain service status           # 查看状态、pid、日志位置
```

单元文件：`~/.config/systemd/user/you-brain.service`，内容由 `you-brain service install --print` 可以预览。

如果没有 `loginctl enable-linger`，服务只会在该用户登录后启动——服务器重启后可能一直不跑。这一步需要 root。

其他管理命令：

```bash
you-brain service install --no-start   # 只写单元，不立即启动
you-brain service uninstall            # 停止并删除单元
you-brain uninstall                    # 停止服务 + 撤销 AI 客户端接入 + 可选删除数据
```

### 6.5 设为主设备

每日全局沉淀由主设备负责：

```bash
you-brain devices                     # 列出所有设备，找到这台机器的 id
you-brain devices --set-main <id>
you-brain devices --set-web-processor <id>   # 可选，默认跟随主设备
```

服务器作为主设备的典型配置是：`capabilities` 为 `["refine", "consolidate"]`（不含 `capture`），设备页会显示为「服务器」。

### 6.6 远程访问 Web 界面

daemon 只监听 `127.0.0.1`，不对外暴露。端口是随机的，以 `status` 输出为准：

```bash
you-brain status
# ...
# Web 界面：http://127.0.0.1:52490
#   远程查看：ssh -N -L 52490:127.0.0.1:52490 <用户>@<这台机器>
```

在自己电脑上执行那条隧道命令，然后浏览器打开 `http://127.0.0.1:52490`。也可以用 Tailscale 之类的组网工具直接访问回环地址。

**不要**改成监听 `0.0.0.0`：API 只有一个静态 bearer token，暴露到公网等于把全部会话原文和数字分身公开。

### 6.7 服务器上的密钥存放

Linux 桌面端用 `secret-tool`（Secret Service）存密钥，无界面的服务器通常没有这个服务。服务器角色会自动改用**文件后端**：

```
<dataDir>/secrets.json      权限 0600
```

可以用环境变量覆盖：

| 变量 | 作用 |
|---|---|
| `YOU_BRAIN_SECRET_BACKEND=file` | 强制用文件后端 |
| `YOU_BRAIN_SECRET_BACKEND=keychain` | 强制用系统钥匙串 |
| `YOU_BRAIN_SECRETS_FILE=/run/secrets/you-brain.json` | 指定密钥文件路径 |

文件里存的是 refresh token、OAuth client secret 和模型 API Key，格式是 `{"<service>\0<account>": "<value>"}`。备份和迁移时注意这个文件等价于账号凭据。

## 7. 数据与目录

### 7.1 目录位置

| 内容 | macOS | Linux |
|---|---|---|
| 数据目录 | `~/Library/Application Support/you-brain/` | `~/.local/state/you-brain/`（遵循 `XDG_STATE_HOME`） |
| 给 AI 读的输出 | `~/.you-brain/` | `~/.you-brain/` |
| 模型缓存 | `<数据目录>/models/` | 同左 |

可用环境变量覆盖：

| 变量 | 作用 |
|---|---|
| `YOU_BRAIN_DATA_DIR` | 数据目录（数据库、配置、密钥、日志） |
| `YOU_BRAIN_HOME` | 输出目录（`TODAY.md` 等） |
| `YOU_BRAIN_WEB_DIR` | Web 界面目录 |
| `YOU_BRAIN_MODEL_CACHE` | 嵌入模型缓存目录 |

### 7.2 数据目录内容

```
config.toml          设备身份、角色、OAuth 模式、账号（0600）
shared.json          采集规则、模型 Provider、话题册参数、提醒设置
roles.json           主设备 / 网页会话处理设备 / 时区
state.sqlite         本地库：会话、事件、话题、待办、游标
search-index.sqlite  语义检索索引
secrets.json         密钥（仅服务器角色或显式指定时）
setup.json           setup 进度
daemon.json          HTTP 端口与 token（运行中）
daemon.lock          daemon 锁
logs/daemon.log      launchd / 前台模式的日志
models/              嵌入模型缓存
```

本地 SQLite 是 Drive 数据的**派生副本**，删掉可以从 Drive 重建；`secrets.json` 和 `config.toml` 则不可重建。

### 7.3 备份

需要备份的只有：

- `config.toml`（设备身份，`deviceId` 一旦写入不可更改）
- `secrets.json`（服务器角色的授权）

其余都在 Drive 上或可重建。

## 8. 运行机制

### 8.1 进程模型

```
you-brain daemon      常驻核心服务：采集、上传、提炼、同步、调度、本地 HTTP API
you-brain mcp         MCP stdio 服务，由 AI 客户端拉起，只读本地库
you-brain <command>   CLI，通过本地 HTTP API 与 daemon 通信
Tauri 外壳            仅桌面端：菜单栏 + WebView，启动时确保 daemon 在运行
```

同一台设备只允许一个 daemon，通过锁文件保证。

### 8.2 主要周期

| 周期 | 间隔 |
|---|---|
| 主循环 tick | 1 秒 |
| 事件 flush | 30 秒 |
| 心跳（写入设备表） | 5 分钟 |
| Drive 拉取 | 60 秒（有界面订阅时 5 秒） |
| 全量扫描兜底 | 10 分钟 |
| 提醒生成 | 10 分钟 |
| 沉淀检查 | 10 分钟 |
| 搜索索引更新 | 60 秒 |
| 网页会话检查 | 60 秒 |
| 数字分身刷新 | 24 小时 |

采集以文件监听为主（250 毫秒防抖），全量扫描只是兜底。

### 8.3 会话提炼触发

- **本地 CLI 会话**：会话空闲 5 分钟后，由产生它的设备先上传再提炼
- **网页会话**：处理设备通过 Drive 变更游标发现，文件空闲 5 分钟后提炼

会话继续增长时只把「上次提炼结果 + 新增消息」交给模型，不重复处理全文。

## 9. 环境变量

| 变量 | 作用 |
|---|---|
| `YOU_BRAIN_DATA_DIR` | 数据目录 |
| `YOU_BRAIN_HOME` | 输出目录 |
| `YOU_BRAIN_WEB_DIR` | Web 界面目录 |
| `YOU_BRAIN_MODEL_CACHE` | 嵌入模型缓存 |
| `YOU_BRAIN_SECRET_BACKEND` | `file` 或 `keychain` |
| `YOU_BRAIN_SECRETS_FILE` | 密钥文件路径 |
| `YOU_BRAIN_GOOGLE_OAUTH_CLIENT_ID` | 源码运行时注入官方凭据 |
| `YOU_BRAIN_GOOGLE_OAUTH_CLIENT_SECRET` | 同上 |

构建相关（`scripts/build-daemon.ts`）：`YOU_BRAIN_GOOGLE_OAUTH_CLIENT_ID` / `_SECRET` 会在编译时通过 `--define` 写进产物，也可以放在 `~/.config/you-brain/release.env`。

## 10. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `you-brain status` 显示 daemon 未运行 | 服务没装或已退出 | `you-brain service status`；服务器上确认执行过 `loginctl enable-linger` |
| 登录打印「本地授权端口 53682 被占用」 | 上一次登录没结束，或别的进程占了端口 | 关掉占用进程后重试；`lsof -i:53682` 查看 |
| 授权链接打开后一直等到超时 | SSH 隧道没开或已断开 | 保持隧道窗口开着，重新点登录 |
| 每 7 天要求重新登录 | OAuth 应用停在 Testing | 把应用发布到 Production，或 User type 改为 Internal |
| `Secret Service is unavailable` | 桌面 Linux 没有 gnome-keyring / kwallet | 启动钥匙串服务，或设 `YOU_BRAIN_SECRET_BACKEND=file` |
| 服务器上 `setup` 报「不是交互终端」 | 缺少 `--yes` 或 `--skip-brainhub` | 补上对应参数 |
| 界面显示「没有找到 Web 界面」 | `web/` 目录缺失 | 重新运行 `install.sh`；或设 `YOU_BRAIN_WEB_DIR` |
| 采集为空 | 服务器角色不采集本机会话 | 正常行为；桌面端才会采集 |
| `native-check` 失败 | vendor 里的原生模块与平台不匹配 | 重新在目标平台构建 |

日志：

```bash
# 服务器（systemd 用户单元）
journalctl --user -u you-brain -f

# macOS 或前台运行
tail -f <数据目录>/logs/daemon.log
```

## 11. 已知限制

- **服务器包未在真实 Linux 上出包验证**：`server-linux.yml` 需要手动触发；真实 `systemctl` / `loginctl` 流程也未跑过完整一轮。
- **网页会话的插件文件格式没有真实样本**：缺少 `turn_count` 时按正文数轮次推断。
- **嵌入模型首次使用需要下载**：会缓存到 `<数据目录>/models/`，离线机器需提前拷入。
- **受限范围审核未做**：官方凭据目前是测试模式；用自己的 OAuth 项目可绕开。
- 手机端、Windows 不在支持范围内。

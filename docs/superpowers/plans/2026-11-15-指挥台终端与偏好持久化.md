# 指挥台终端体验、偏好持久化、会话提醒、「记忆」入口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 界面偏好不再随重装丢失；内嵌终端整屏、可调字号、更顺滑；终端会话等待或完成时弹系统通知；顶部菜单收成「指挥台、记忆、知识库」。

**Architecture:** 偏好由 daemon 存进数据目录的 JSON 文件，随 `index.html` 注入首屏，网页用一个同步读、异步写的 `prefs` 对象替换 localStorage。终端仍直连 tty7 原 pane（ADR-0004），只把呈现从弹窗换成覆盖整个窗口的一层，会话数据用一个共享 hook 供列表、角标、整屏三处使用。提醒由 daemon 监视 tty7 会话状态变化产生通知条目，桌面壳拉取后弹系统通知。

**Tech Stack:** Bun + TypeScript（`packages/core` daemon、`apps/web` React + Vite）、xterm 6 + `@xterm/addon-webgl`（已获授权的唯一新依赖）、Tauri 2 / Rust（`apps/desktop/src-tauri`）、tty7 CLI。

**Spec:** `docs/superpowers/specs/2026-11-15-指挥台终端与偏好持久化-design.md`

**执行模型：** 本人指定 Sonnet 5.5（`claude-sonnet-5-5`）执行，不从这一档升级。

**Interfaces:**
- Produces:
  - `type UiPrefs = Record<string, string>`；`interface UiPrefsPatch { set?: Record<string, string>; remove?: string[] }`
  - `class UiPrefsStore { constructor(file: string); read(): Promise<UiPrefs>; patch(input: UiPrefsPatch): Promise<UiPrefs> }`，文件为 `<dataDir>/ui-prefs.json`，权限 0600。
  - `class UiPrefsLimitError extends Error`
  - `HttpDeps.uiPrefs: { read(): Promise<UiPrefs>; patch(input: UiPrefsPatch): Promise<UiPrefs> }`
  - `GET /api/ui-prefs` → `{ prefs: UiPrefs }`；`PUT /api/ui-prefs`，请求体 `UiPrefsPatch`，返回 `{ prefs: UiPrefs }`；超限返回 413、错误码 `PAYLOAD_TOO_LARGE`。
  - 页面注入：`window.__YOU_BRAIN__ = { token, prefs }`。
- 限制值：键 1～200 字符；单个值 ≤ 65536 字符；整个文件序列化后 ≤ 1048576 字节。

    - `previous` 为 `null`（第一次快照）时返回空。
    - 只有上一次是 `"working"`、这一次是 `"waiting"` 或 `"done"` 的会话产生条目。

  - `class SessionNoticeWatcher`，构造参数 `{ sessions(): Promise<Tty7SessionsView>; subscribe(onLine: () => void): () => void; enabled(): Promise<boolean>; onNotice(): void; now?(): number; pollMs?: number; debounceMs?: number }`；方法 `start(): void`、`stop(): void`、`setViewing(pane: number | null): void`、`list(): { epoch: string; latest: number; notices: SessionNotice[] }`。
    - `pollMs` 默认 30000，`debounceMs` 默认 300：事件流每来一行，去抖后重读一次会话；另有 30 秒一次的兜底读取。同一时刻只有一次读取在跑。

    - `setViewing` 的值 15 秒后过期（视为 `null`）。
    - `enabled()` 为假时照常更新快照但不产生条目。
    - `sessions()` 抛错：本轮跳过，保留上一次快照，不产生条目，不抛出。

> 2026-11-15 ｜ 状态：待本人审阅 ｜ 范围：本期。下期事项见 `docs/TODO.md` 的 I 节。
> 标注「我定的」的条目是设计者的决定，未经本人逐条确认，审阅时请重点看。

## 为什么做

U-Brain 要成为个人的超级入口，日常主力是 T3 和终端，DSH 低频。现在有三件事每天都在妨碍使用：

1. 重装或 daemon 重启后，界面偏好（终端分组背景色、展开状态、只看活跃、主题、T3 地址等）全部丢失。
2. 内嵌终端不如直接用 tty7：在弹窗里、一屏内容少、有延迟、中文标点有问题，所以经常切回 tty7。
3. 终端里的 agent 干完了或在等回复，没有任何提醒，只能自己去看。

另外，「今日」和「话题册」不是用来浏览的页面，而是记忆库，不该各占一个主菜单。

## 目标

- 界面偏好在重装、daemon 重启、端口变化后都保留。
- 内嵌终端达到「不必再开 tty7」的程度：整屏、字号可调、输入输出顺滑、中文标点正常。
- 终端会话变成「等你回复」或「已完成」时弹系统通知。
- 顶部菜单变成：指挥台、记忆、知识库。

## 不做

- 不改 T3：仍是原样的内嵌页面。
- 终端不加终端以外的功能（不加命令面板、AI 辅助、分屏等）。
- 不改「今日」「话题册」的内容和数据，只改入口位置。
- 不做全应用的视觉重做（等 Magpie 截图，见 TODO I2）。
- 不做记忆检索增强、月度回顾、时间节点提醒、跨项目建议（见 TODO I3～I6）。
- T3 的完成提醒不在本期（T3 的状态怎么拿还没查，见 TODO I1）。

## 反目标

- 为了像 tty7 而另起一套终端后端。仍然直连 tty7 原 pane 的真实终端流（ADR-0004），只改前端呈现。
- 偏好换个地方存，但仍然会因为某种环境变化丢失。
- 提醒太多变成噪音：一次状态变化只弹一次，正在看的会话不弹。

## 一、界面偏好持久化

**根因（已核实）**：偏好存在 localStorage；界面从 `http://127.0.0.1:<端口>/` 加载，daemon 未指定端口时由系统随机分配（`packages/core/src/http/server.ts`，当前 `daemon.json` 里是 49176）。端口一变即换源，旧数据读不到。

**做法**：偏好交给 daemon 存进数据目录（`~/Library/Application Support/you-brain/` 下一个 JSON 文件），界面通过本机接口读写，不再依赖源。

- 纳入的键：`apps/web/src` 里所有表达「用户选择」的 localStorage 键。至少包括 tty7 的分组颜色、展开分组、只看活跃、默认 harness、会话面板开合、指挥台当前页（DSH/T3）、T3 地址、主题、知识库侧栏宽度与宽屏开关、知识库折叠与数据库视图状态，以及本期新增的终端字号。
- 不纳入：纯缓存（启动快照 `BOOT_SNAPSHOT_KEY`、知识库页面缓存 `CACHE_KEY`）。丢了能重建，留在 localStorage。
- 首屏不闪：主题要在第一帧前生效。daemon 已经会往 `index.html` 注入令牌，偏好随同注入。（我定的）
- 机制层只认「键、值」，不认识具体业务名词；单个值和总大小设上限，超限拒绝写入并报错，不静默截断。
- 写入失败时本次操作照常生效，只是不持久，界面给出一次可见提示。
- 一次性迁移：升级后首次打开，当前源的 localStorage 里若还有旧键，且 daemon 侧没有对应值，则写入 daemon。旧端口下的数据已读不到，不强求找回。（我定的）
- 仅本机，不随 Drive 同步到其他设备。（我定的）

**没选的方案**：固定端口。改动最小，但端口被占用时要么启动失败要么退回随机端口，问题会再次出现。

## 二、指挥台布局

- 主体仍是 DSH / T3 切换，两页保持挂载。**首次使用默认选中 T3**（现在是 DSH），之后记住上次选择。
- 会话列表面板可收起。收起后**右侧不留窄边**，T3 占满宽度。
- 指挥台工具栏右上角放一个终端图标按钮，点击展开或收起会话列表。有会话处于「等你回复」时，图标上显示数量角标。（角标是我加的）
- 会话列表本身的内容和现有一致（分组、颜色、筛选、只看活跃、新建、删除）。

## 三、终端整屏

点会话后，终端铺满整个窗口内容区，不再用弹窗（现为 `deck-tty7.tsx` 里的 `Dialog size="full"`）。

**顶部只有一行**，从左到右：

1. **返回**：收起终端回到之前的页面。不结束会话。
2. **已打开的会话标签**：本次使用中点开过的会话，跨项目。每个标签有项目色、状态圆点、标题；可单独关闭（只移出标签，不结束会话）。标签过多时横向滚动。
3. **下拉按钮**：全部会话的列表，按项目分组、可输入筛选，内容与外面的会话列表一致。选中即在当前整屏打开并加入标签。下拉里可以新建会话。（新建入口是我加的）
4. **字号调节**：最右，A−、当前字号、A+。

**整屏时去掉**：弹窗边框和标题栏、状态与型号的元信息行、终端下方的直通提示文字。连接状态、错误、粘贴中这类信息只在出现时以悬浮条显示，不常驻占位。「等你回复」的那句话保留，显示在标签的悬停提示里。（我定的）

**改名**：双击标签或列表里的会话名进入编辑，回车提交，Esc 取消。写回 tty7（`tty7 tab rename`），不另存一份。一个 tab 里有多个 pane 时改的是 tab 名，这些 pane 一起变。未手动起名的会话继续显示 tty7 的自动标题。改名失败时恢复原名并显示错误。

**键盘**：Esc 仍然直通给终端，不用来返回。返回和切换标签的快捷键由实现者定，但不能占用终端里常用的组合键。

## 四、终端手感

目标是接近 tty7。已知的三处差距和对应做法：

| 问题 | 现状 | 做法 |
|---|---|---|
| 一屏内容少 | 弹窗 + 字号写死 13、行高 1.25、内边距 10px | 整屏；字号可调并记住；默认字号、行高、字体取本机 tty7 的实际配置对齐，取不到时默认 12 / 1.2（我定的） |
| 延迟 | xterm 默认渲染 | 换用 xterm 的 GPU 渲染扩展，不可用时自动退回现有方式。新依赖已获本人授权（2026-11-15），仅限 xterm 官方的 GPU 渲染扩展 |
| 中文标点 | 未定位 | 先复现再定位根因，不做现象补丁。复现用例：中文输入法下输入 `，。、；：？！“”‘’（）《》【】……——`，分别在 shell 提示符和 Claude Code 输入框里试 |

延迟要有数据：改动前后各测一次「按键到字符上屏」的耗时，用同一会话同一操作，结果写进交付说明。若换渲染方式后仍明显慢于 tty7，继续沿链路（WebSocket、daemon 转发、ack 机制）查，不就此收工。

## 五、会话提醒

- **触发**：某个终端会话的状态从「工作中」变成「等你回复」或「已完成」。状态来自 tty7 的 agent hooks 上报，没有状态的会话（没装 hooks）不提醒。
- **不弹的情况**：U-Brain 窗口在前台，且正整屏显示的就是这个会话。
- **去重**：一次状态变化只弹一次；daemon 或应用重启不补弹重启前已处于该状态的会话。
- **内容**：标题是「<会话名> 在等你回复」或「<会话名> 已完成」，正文是 tty7 给的状态附言，没有就留空。
- **点击**：不做跳转。通知只负责提醒，点击后的行为保持系统默认（本人 2026-11-15 定）。
- **检测位置**：放在 daemon 或桌面壳，不放在网页里，这样主窗口关着也能提醒。优先用 tty7 的事件流（`tty7 events`），不新增高频轮询。（我定的）
- **通道**：复用桌面壳已有的系统通知（`tauri-plugin-notification`，现用于话题提醒）。
- **开关**：设置里一个总开关，默认开。（我定的）

## 验收

1. 设置分组颜色、展开分组、只看活跃、主题、终端字号后，按 `CLAUDE.md` 的完整流程重新打包安装，重开后全部保留。只重启 daemon 也保留。
2. 会话列表收起后右侧无窄边；右上角按钮可展开；有等待会话时显示角标且数字正确。
3. 点会话后终端占满窗口内容区，顶部只有一行；标签可切换、可关闭；下拉能打开未在标签里的会话并能新建；返回后会话仍在运行。
4. 双击改名后，tty7 里同一 tab 的名字同步变化；重装后名字仍在。
5. 字号调节即时生效，重开后保留；同一窗口尺寸下，默认设置的行列数不少于 tty7。
6. 复现用例里的中文标点全部正确上屏，shell 和 Claude Code 里都试过。
7. 按键上屏耗时有改动前后的数据。
8. 让一个会话进入「等你回复」和「已完成」：应用在后台时各弹一次通知；正整屏看着该会话时不弹；重启应用不补弹。
9. 顶部菜单为三项；「记忆」页两个分段内容与原页面一致；旧地址和面板里的跳转都能到达。
10. 项目全局测试、类型检查通过。网页部分由本人按真实路径点一遍。

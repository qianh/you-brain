# ADR-0001：指挥台主控复用本机 AI CLI + skill，不在 daemon 里自研编排循环

状态：已被 ADR-0003 取代（2026-11-03）——旧主控与自研指挥台已删除，由 DeepSeek Harness 承担。

## 背景

指挥台需要一个「主控」：读用户指令，判断当场执行还是登记成周期任务，再派活给四类执行者。两条路：

1. daemon 内自研 agent 循环（工具调用、多轮、自主决策全自己写）
2. 复用本机已登录的 AI CLI 跑 agent 模式，配一份调度 skill 描述路由规则与可用接口

## 决策

选 2。主控是一个可配置的本机 AI CLI（默认从已检测的五个里选），复用 `llm/cli` 既有基座：provider 定位、登录检测、超时与失败分类、专用 workdir。skill 沿用 `skills/you-brain` 的模式新写一份：路由规则（当场 vs 周期）、执行者清单、各接口调用方式。skill 是策略，daemon/CLI 是机制。

## 后果

- 编排能力跟随 CLI 生态免费升级；用户用已有的订阅，不新增模型费用入口。
- 「按需还是排程」的判断交给 agent 按 skill 路由，产品界面不出现两个功能入口，符合「用户只表达意图」。
- 代价：主控行为不完全可控，依赖外部 CLI 的存在与输出稳定性；由 skill 约束行为、由驱动层兜底失败。
- 主控 CLI 是用户可换的配置，不是硬编码某一家。

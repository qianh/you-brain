# ADR-0004：指挥台直接指挥 tty7 里的终端会话

状态：已接受（2026-11-13）；2026-11-14 改为真实终端连接。补充 ADR-0003，不取代它。

## 背景

ADR-0003 把指挥台整页交给 dsh。实际做项目开发时，用户并不用 dsh 的 harness，而是在 tty7（终端 TUI）里按项目开会话，在会话里跑 Claude Code、Codex 等 AI CLI。指挥台要成为下达指令的总入口，就得能看到这些会话、往里面发指令、新开会话；真正干活仍在各自的 CLI 里。

tty7（26.10.0）的命令行本身就是给编排用的：全部非交互、带 `--json`，覆盖列会话、读屏幕、发输入、新建 tab。

## 决策

1. **指挥台页 = dsh 界面 + tty7 会话面板**。面板是 U-Brain 自己的界面，在 iframe 右侧，可收起；dsh 在启动或出错时面板照常可用。
2. **会话管理经 CLI，终端交互直连 socket**。列表、新建和删除使用 `tty7 --json`；交互视图通过 daemon 的同源 WebSocket `/api/deck/tty7/terminal`，接入 tty7 协议 6 的原始终端流。WebSocket 先检查 Origin，再在首帧验证 daemon 令牌，令牌不放进 URL。
3. **会话 = 一个 pane**（`%N`）。标题和 agent 名取 tty7 自己在 tab 上识别出的（`tty7 tab ls`），不自己猜进程名。
4. **逐键操作原会话**：Web 端用 xterm 渲染 ANSI、光标、颜色、鼠标和全屏界面，并编码按键、输入法、粘贴及终端查询应答。输入经二进制 WebSocket 和 tty7 `SendInput` 原样送达，按 ACK 排序，不使用本地草稿、按键白名单、读屏轮询或每键 CLI 子进程。`/` 菜单由原会话里的 CLI 自己生成。旧的 `screen` / `send` HTTP 接口保留给非交互调用。
5. **新开会话**：在选定目录 `tty7 tab new --cwd`，等 shell 提示符出来后敲入所选 CLI 的启动命令。可选 CLI 是代码里的一张固定表（`TTY7_HARNESSES`），接口不接受任意命令。
6. **保留原窗口连接**：使用 `Observe` 接收回放和实时输出，不用会顶掉原控制端的 `Attach`。通过 `size-lease` 临时使用嵌入区域的行列数；视图关闭、切换会话或断线时释放 observer，tty7 自动恢复原控制端尺寸，不结束原 pane。握手先检查协议版本和能力，不兼容时明确报错。
7. **不保存会话内容**：终端回放和滚动缓冲只在内存中；会话原文进数字资产仍走各 CLI 自己的采集适配器。浏览器在解析输出后 ACK，daemon 对慢客户端暂停读取，避免持续输出挤满渲染队列。
8. **删除会话**：列表每条会话提供删除入口，确认框注明标题、pane 编号和结束运行中任务的影响。认证接口 `POST /api/deck/tty7/delete` 严格接受单个 pane 编号，调用 `tty7 pane close %N --json`，只关闭目标 pane，保留同一 tab 中的其他 pane；失败时保留列表项并显示错误。关闭交互视图仍只释放连接。

## 后果

- 任何拿到 daemon 令牌的本机进程都能往终端里打字。daemon 接口本来就只监听本机并要求令牌，这里没有再加一层确认。
- 会话的运行状态（运行中 / 等你回复 / 已完成 / 空闲）来自 `tty7 agents`，依赖 tty7 的 agent hooks：在 tty7 的 Settings → Integrations 里按 CLI 逐个安装，命令行没有安装入口。没装 hooks 的 CLI、以及装之前就启动的会话不上报状态，面板里只是不显示状态标记。本机 2026-11-13 已装 Claude Code 和 Codex。
- GUI 启动的 daemon 的 PATH 里通常没有 Homebrew，所以定位 `tty7` 时除了 PATH 还查 `/opt/homebrew/bin`、`/usr/local/bin`、`/Applications/tty7.app`。
- 未做：dsh 插件（让指挥台对话里的模型去派给 tty7 会话）。接口已可复用，需要时照 `u-brain-bridge` 的做法加。
- 兼容性基线为 tty7 26.10.0 / 协议 6 / `size-lease`；升级后要重跑真实会话验证。
- 嵌入的是同一个 PTY，会话内程序的菜单和操作由程序自身处理。tty7 GPUI 窗口的标签页、分屏和系统快捷键不属于该接口；独立传输的 kitty graphics / OSC 5522 剪贴板消息目前提示回原窗口查看，不能宣称与 tty7 整个原生窗口完全等价。

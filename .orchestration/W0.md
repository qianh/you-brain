## 目标
后续会有 5~6 个开发者**并行**在 packages/core/src/<模块>/ 下开发，他们不允许改 package.json。所以你必须一次性把整个项目需要的依赖装好，并把公共基础层写稳。

## 1. Monorepo 骨架（bun workspaces）
```
package.json            # private, workspaces: ["packages/*", "apps/*"]; scripts: test / typecheck（遍历各包）
tsconfig.base.json      # strict, ESNext, moduleResolution bundler, types: ["bun-types"] 或 @types/bun
packages/protocol/      # @you-brain/protocol
packages/core/          # @you-brain/core（src/ 下按技术方案第 3 节建空目录占位：adapters capture drive upload sync refine topics consolidate portrait reminders search llm store output mcp http clients auth migrate daemon domain，每个放 index.ts 导出空对象即可，不写 .gitkeep）
packages/cli/           # @you-brain/cli，src/index.ts，bin: you-brain，先只实现 `you-brain --version`
apps/web/               # 先只建 package.json 占位（React + Vite 由后续任务做），不要装前端依赖
```
包之间用 `workspace:*` 引用；core 依赖 protocol，cli 依赖 core 和 protocol。各包 tsconfig 继承 base，可以直接引用 src（不需要先 build）。

## 3. packages/protocol（技术方案第 4、6 节）
用 zod 定义并导出（同时导出 TS 类型）：
- `PROTOCOL_VERSION = 1`，以及 protocol.json 的 schema
- Drive 目录约定常量/函数：inbox 路径、`you-brain/config/shared.json`、`roles.json`、`devices/<id>.json`、`events/<deviceId>/<YYYY-MM-DD>.jsonl`、`leases/consolidate.json`、topics/、digital-twin/ 等，路径都相对根目录（默认 `brain-hub`）
- DeviceRecord（6.1）、Roles（6.2）、SharedConfig（6.2 + 产品说明 5.3 中除 API Key 外的所有配置项，全部带默认值：活跃上限 10、历史天数 30、空闲 5 分钟、沉淀 03:00、portrait 默认三个变体等）
- 事件：通用信封（v, id, ts, device, seq, type, data）+ 6.3 表中**全部 15 种**事件类型的 data schema，做成 discriminated union；提供 `parseEvent`、`serializeEventsJsonl`、`parseEventsJsonl`（逐行解析，坏行跳过并报告）
- 提炼模型输出 schema（7.2 的 JSON）
- 话题状态枚举（进行中/待跟进/已完结/搁置 → `active | follow_up | done | parked`）、todo 状态 `open | done | dropped`
- ULID 生成工具、`conversationKey(source, conversationId)`（sha256(source + "\0" + conversationId)，与参考实现 src/domain/session.ts 保持一致）
- 给 inbox 文件的 appProperties 键常量（brainhubKey/source/conversationId/deviceId/updatedAt/contentSha256/ybSchema）

## 4. packages/core/src/domain
从参考实现 src/domain/（session.ts、errors.ts、platform.ts、config.ts、config-io.ts）搬运并改造：
- 本地配置（设备本地，不同步）：deviceId（不可变 UUID）、displayName、driveRoot、oauth 模式（official / custom client）、本机数据目录。
- 路径：技术方案 9.1（macOS `~/Library/Application Support/you-brain/` + `~/.you-brain/`；Linux XDG_STATE_HOME），所有路径函数支持通过环境变量 `YOU_BRAIN_DATA_DIR` / `YOU_BRAIN_HOME` 覆盖（测试和多 daemon 端到端用）。
- 会话领域类型 NormalizedSession / NormalizedMessage 等（沿用参考实现）。
- 原子写文件工具 `writeFileAtomic`（先写临时文件再 rename）。
